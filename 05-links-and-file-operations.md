# Жесткие и символические ссылки

## О чем этот раздел
В Linux файлы — это указатели на данные (inode). Ссылки позволяют создавать «ярлыки» на эти данные.

## Ключевые концепции
*   **Жесткая ссылка (`ln`)**: Создает второе имя для тех же данных на диске (тот же inode). Если удалить оригинал, данные останутся доступны через ссылку. Работает только внутри одной файловой системы.
*   **Символическая ссылка (`ln -s`)**: Это отдельный файл, который хранит *путь* к оригиналу. Похоже на ярлык в Windows. Если удалить оригинал, ссылка «сломается».
    *   `ln -s /path/to/original my_link` — создать симлинк.
    *   `readlink my_link` — узнать, куда ведет ссылка.

## Особенности
*   Симлинки бывают **относительными** (ломаются при перемещении) и **абсолютными** (работают всегда).
*   `ls -l` показывает симлинки со стрелочкой `->` и буквой `l` в начале прав.
