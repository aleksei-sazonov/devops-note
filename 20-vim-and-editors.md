# Тема: Редактор Vi и работа с файлами на сервере

## TL;DR (Суть в 3 строках)
`vi` (или `vim`) — это модальный редактор, установленный по умолчанию на любом Linux-сервере. Он работает в двух основных режимах: командном (навигация и удаление) и вставки (печать текста). Писк в `vi` — это не поломка, а звуковой сигнал о невозможности выполнить действие (например, переход за границу файла или `Esc` в командном режиме).

## Ключевые концепции
- **Режимы `vi`**: 
  - *Командный (Normal)*: Режим по умолчанию. Клавиши управляют курсором и текстом (`hjkl` для навигации).
  - *Вставки (Insert)*: Режим печати. Вход по клавише `i`, выход по `Esc`.
  - *Последней строки*: Вход по `:`, используется для сохранения, выхода и настроек.
- **Писк (Beep)**: Возникает, когда действие невозможно (конец файла, пустой файл) или при нажатии `Esc` в командном режиме.
- **Удаление как "Вырезать"**: В `vi` команда `dd` (удалить строку) на самом деле вырезает её в буфер обмена. Её можно вставить в другом месте через `p`.
- **Современные альтернативы**: Для комфортной работы по SSH используют `nano` (простой, как блокнот) или VS Code с расширением Remote - SSH.

## Команды / Синтаксис (Шпаргалка выживания)
```bash
# --- ЗАПУСК ---
vi filename.txt

# --- РЕЖИМЫ ---
i       # Войти в режим вставки (начать печатать)
Esc     # Выйти в командный режим (прервать печать)

# --- ВЫХОД ---
:wq     # Сохранить и выйти (w - write, q - quit)
:q!     # Выйти БЕЗ сохранения (принудительно, если всё сломал)

# --- НАВИГАЦИЯ (в командном режиме) ---
h j k l # Влево, вниз, вверх, вправо (альтернатива стрелкам)
0       # В начало строки
$       # В конец строки
G       # В самый конец файла
gg      # В самое начало файла

# --- РЕДАКТИРОВАНИЕ (в командном режиме) ---
x       # Удалить один символ под курсором
dw      # Удалить слово
dd      # Удалить (вырезать) всю строку
u       # Отменить последнее действие (Undo)
p       # Вставить вырезанное (после dd)

# --- ОТКЛЮЧЕНИЕ ПИСКА (на время сессии) ---
