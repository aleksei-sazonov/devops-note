# Отладка ссылок и базовые ошибки

## О чем этот раздел
Понимание того, как не сломать систему при работе с файлами.

## Частые ошибки
1.  **`rm: cannot remove 'folder': Is a directory`**
    *   *Причина*: попытка удалить папку командой `rm` без флага.
    *   *Решение*: `rm -r folder`.
2.  **`ln: failed to create symbolic link: File exists`**
    *   *Причина*: `ln -s` ожидает аргументы `<цель> <имя_ссылки>`. Если имя не указано, он пытается создать ссылку с именем цели, а такой файл уже есть.
    *   *Решение*: `ln -s /path/to/file my_new_name`.
3.  **Сломанный симлинк (`No such file or directory`)**
    *   *Причина*: Оригинальный файл переместили или удалили, либо ссылка была относительной и «переехала» вместе с папкой.
    *   *Решение*: Создавать симлинки с абсолютным путем.

## Полезные флаги
*   `ls -ld folder` — показать права на саму папку, а не на ее содержимое.
