# Справка и перенаправление потоков (I/O)

## О чем этот раздел
Linux построен на принципе: «одна программа делает одно дело, но делает его хорошо». Чтобы связывать программы и сохранять их вывод, используются потоки.

## Потоки
1. **stdout** (стандартный вывод) — то, что программа печатает на экран.
2. **stderr** (стандартные ошибки) — сообщения об ошибках.
3. **stdin** (стандартный ввод) — то, что передается в программу.

## Ключевые команды
*   **Получение справки**:
    *   `команда --help` — краткая справка.
    *   `man команда` — полное руководство (выход по клавише `q`).
*   **Перенаправление вывода**:
    *   `команда > file.txt` — перезаписать файл результатом команды.
    *   `команда >> file.txt` — добавить результат в конец файла (не стирая старое).
    *   `команда 2> error.txt` — перенаправить только ошибки в файл.
*   **Пайпы (`|`)**: Передают вывод одной команды на вход другой.
    *   `ls -la | head -n 5` — показать только первые 5 строк вывода `ls`.
    *   `ps aux | grep nginx` — найти процесс nginx в общем списке.
