# Группы и права доступа (Практика)

## О чем этот раздел
Понимание того, как разграничить доступ к файлам между пользователями.

## Ключевые концепции
*   **Три категории**: Владелец (`u`), Группа (`g`), Остальные (`o`).
*   **Цифровая маска**: `r` (чтение) = 4, `w` (запись) = 2, `x` (выполнение) = 1.
    *   `chmod 755 file` -> `rwxr-xr-x` (владелец всё, остальные чтение/выполнение).
    *   `chmod 644 file` -> `rw-r--r--` (владелец чтение/запись, остальные только чтение).
*   **Специальные права**:
    *   **SGID (`2...`)**: Устанавливается на папку. Все новые файлы внутри наследуют группу этой папки, а не группу создателя. Идеально для командной работы.
    *   **Sticky Bit (`1...` или `+t`)**: Устанавливается на папку. Удалять файлы могут только их владельцы (или root). Используется в общих папках, например `/tmp`.
*   **`umask`**: Это НЕ права, а **маска того, что нужно ОТНЯТЬ** от базовых прав. Например, `umask 027` убирает запись у группы (2) и все права у остальных (7).

## Ключевые команды
*   `chmod 2770 team_share` — папка для команды (владелец+группа всё, SGID для наследования).
*   `chmod 1777 /tmp` — общая папка со Sticky Bit.
*   `sudo addgroup user group` — добавить пользователя в группу.
