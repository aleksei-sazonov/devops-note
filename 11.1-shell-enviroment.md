# Тема: Настройка окружения оболочки (Shell Environment)

## TL;DR (Суть в 3 строках)
Оболочка (bash) читает конфигурационные файлы (в основном `~/.bashrc`), чтобы загрузить переменные, алиасы и настройки при старте. Мы можем редактировать этот файл, чтобы автоматизировать рутину и настроить систему под себя.

## Ключевые концепции
- **Переменные окружения**: Данные (текст), которые хранятся в системе и доступны программам (например, `$PATH`, `$HOME`, `$USER`).
- **Алиасы (Псевдонимы)**: Короткие команды, заменяющие длинные (например, `ll` вместо `ls -alF`).
- **Файлы конфигурации**:
  - `~/.bashrc`: Читается при **каждом** открытии нового терминала. Сюда пишем алиасы, `umask`, настройки истории. **Главный файл для ежедневной работы.**
  - `~/.profile`: Читается при **входе в систему** (логине). Сюда обычно пишут глобальные переменные и `PATH`.
- **`source`**: Команда, которая применяет изменения из файла конфигурации *прямо сейчас*, без открытия нового терминала.

## Команды / Синтаксис (Шпаргалка)
```bash
# --- РАБОТА С КОНФИГАМИ ---
# Сделать бэкап перед редактированием (ЗОЛОТОЕ ПРАВИЛО!)
cp ~/.bashrc ~/.bashrc.bak

# Отредактировать файл
nano ~/.bashrc

# Применить изменения без перезагрузки
source ~/.bashrc

# --- ПЕРЕМЕННЫЕ ---
# Посмотреть все переменные окружения
env  # или printenv

# Посмотреть значение конкретной переменной
echo $PATH

# Создать переменную, доступную скриптам (экспорт)
export MY_VAR="Hello"

# --- АЛИАСЫ ---
# Создать алиас
alias l='ls -d .*'     # только скрытые файлы (как ты сделал)
alias ll='ls -l'       # длинный список

# Посмотреть все активные алиасы
alias

# Проверить, что делает команда (алиас это или бинарник)
type ll
