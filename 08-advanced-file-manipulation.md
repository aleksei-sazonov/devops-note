# Продвинутая работа с файлами (cp, mv)

## О чем этот раздел
Безопасное копирование и перемещение, чтобы случайно не затереть важные данные.

## Ключевые команды и флаги
*   **`cp -v`** (verbose) — показывает, какие файлы копируются в данный момент. Полезно для отладки.
*   **`cp -i`** (interactive) — спрашивает подтверждение перед перезаписью существующего файла. **Жизненно важный флаг!** Спасает от случайного удаления.
*   **`. ` (точка)** — обозначает текущую директорию. `cp file.txt .` — скопировать в текущую папку.
*   **`..` (две точки)** — родительская директория.
*   **Перемещение в подпапки**: `mv file.txt dir1/dir2/` — переместит файл сразу по указанному вложенному пути.
*   **Синтаксис `ln -s`**: Всегда `ln -s <ЦЕЛЬ> <ИМЯ_ССЫЛКИ>`. Ровно два аргумента.

## Частые ошибки
*   Передача трех аргументов в `ln -s` (вызывает путаницу у системы).
*   Опечатки в путях (например, `/home/project/` вместо `/home/labex/project/`).
*   Использование `rm` без `-r` на директориях (`Is a directory`).
