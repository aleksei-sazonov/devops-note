# Настройка оболочки, $PATH и автозагрузка

## О чем этот раздел
Как сделать так, чтобы твои настройки и скрипты сохранялись после перезапуска терминала.

## Ключевые концепции
*   **`~/bin`**: Личная папка пользователя для его собственных скриптов. В отличие от `/bin` (где лежат системные команды, принадлежащие root), в `~/bin` ты можешь класть файлы без `sudo`.
*   **`~/.zshrc` (или `~/.bashrc`)**: Файл конфигурации оболочки. Он читается каждый раз, когда ты открываешь новый терминал.
*   **Добавление в `$PATH`**: Если ты положил скрипт в `~/bin`, система его не найдет, пока ты не скажешь ей: `export PATH="$PATH:$HOME/bin"` (и не запишешь это в `.zshrc`).
*   **`source`**: Команда, которая заставляет терминал перечитать конфиг прямо сейчас (без открытия нового окна).

## Ошибка `dquote>`
Возникает при незакрытой кавычке в терминале. Выход: `Ctrl+C`.
