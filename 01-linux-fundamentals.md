# Основы Linux: Навигация и файлы

## О чем этот раздел
Базовый фундамент работы в терминале. Без этих команд невозможно выполнить ни одну задачу в Linux.

## Ключевые команды и их смысл
*   **`pwd`** (Print Working Directory) — показывает, в какой папке ты находишься прямо сейчас.
*   **`ls`** (List) — показывает содержимое текущей папки. 
    *   *Флаг `-l`*: показывает подробный список (права, владельца, размер, дату).
    *   *Флаг `-a`*: показывает скрытые файлы (начинающиеся с точки, например `.zshrc`).
*   **`cd`** (Change Directory) — переход в другую папку.
    *   `cd /var/log` — перейти по абсолютному пути.
    *   `cd ..` — подняться на уровень выше.
    *   `cd ~` — перейти в домашнюю директорию пользователя.
*   **`touch`** — создает пустой файл (или обновляет дату доступа, если файл существует).
*   **`mkdir`** (Make Directory) — создает папку.
    *   *Флаг `-p`*: создает вложенные папки одной командой (например, `mkdir -p dir1/dir2/dir3`).
*   **`cp`** (Copy) — копирует файлы или папки.
    *   *Флаг `-r`*: рекурсивное копирование (обязателен для папок).
    *   *Флаг `-v`*: показывает процесс копирования.
    *   *Флаг `-i`*: спрашивает подтверждение перед перезаписью.
*   **`mv`** (Move) — перемещает или переименовывает файлы.
*   **`rm`** (Remove) — удаляет файлы.
    *   *Флаг `-r`*: рекурсивное удаление (для папок).
    *   ⚠️ *Осторожно:* в Linux нет «Корзины». Удаленное через `rm` восстановить почти невозможно.

## Права доступа (Базово)
*   **`chmod`** — меняет права (чтение `r`, запись `w`, выполнение `x`).
    *   `chmod +x script.sh` — сделать файл исполняемым.
    *   `chmod 755 file` — владелец может всё, остальные читать и выполнять.
*   **`chown`** — меняет владельца файла (требует прав `sudo`).
