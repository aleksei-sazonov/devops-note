# Создание пользователей: useradd vs adduser

## О чем этот раздел
В Linux есть две команды для создания пользователей, и новички часто путаются, какую использовать.

## Разница
*   **`useradd`**: Низкоуровневая утилита. Она просто создает запись в `/etc/passwd`. По умолчанию она **не создает** домашнюю директорию, не копирует файлы настроек (`.bashrc`) и не просит задать пароль. Требует явных флагов (например, `-m` для создания папки).
*   **`adduser`**: Высокоуровневый скрипт (обычно в Debian/Ubuntu). Он интерактивный: спрашивает пароль, создает домашнюю папку, копирует туда файлы из `/etc/skel` (шаблоны). **Рекомендуется для повседневного использования.**

## Ключевые команды
*   `sudo adduser trainee` — создать пользователя (интерактивно).
*   `id trainee` — проверить, что пользователь создан, и посмотреть его группы.
*   `sudo addgroup trainee developers` — добавить пользователя в группу (сначала имя пользователя, потом имя группы).

## Частая ошибка
Попытка выполнить `addgroup developers trainee` (в обратном порядке). Система подумает, что `developers` — это пользователь, и выдаст ошибку.
